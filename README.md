# Sistema de Gestão Agroecológica e Sustentável
Aplicação desktop para gestão agroecológica e sustentável: zoneamento de terreno, controle de bioinsumos, controle de automações e colheita com desperdício zero.

---

## Sobre o Projeto

Este software foi projetado como Trabalho Final da disciplina de **Programação Orientada a Objetos (POO)** da **Universidade Federal do Ceará (UFC) – Campus Quixadá**.

Além de resolver um problema real ligado à agricultura sustentável e ao contexto climático, a arquitetura aplica rigorosamente os pilares da Orientação a Objetos, persistência local em arquivos e interface gráfica desktop.
